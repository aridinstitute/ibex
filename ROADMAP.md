# Roadmap

In general, you'll want to look at the Github issues by milestone for the most up-to-date roadmap. This file is primarily
intended as a high-level overview of planned features so that agents can consider those as we develop features today. For
that reason, it's just a loose list of planned features and relevant design decisions about them; it does not indicate
release sequence or anything like that.

## AI & Automation
* **AI Research Assistant**: A built-in chat panel that can take actions on your library.
* MCP Server
* **Scripting**: Run a script on certain hooks, like prior to automated classification, etc.
* Fetch citations from PDFs to build a graph of citations
* Extract metadata from PDFs

## Filter & Search
* Filter by most metadata
* Advanced keyword search syntax (AND, OR, NOT)
* Semantic search

## Resources
* Custom metadata/fields
* Attachments
* Notes (Markdown, Latex support)
* Sync with `.bib` files
* Link resources together
* Store table of contents & convert chapters to resources
* PDF highlighting

## Organization
* Hierarchical tags
* User-ordered collections/subcollections
* Collection metadata (description, color)
* Colored tags
* Automatic cluster detection with BerTopic
* Quick Add to collection

## Miscellaneous

* Web app (?)
* Plugins (?)
* Readwise integration
* Custom themes
* Library Stats (dashboard?)
* Author/person metadata
* Metadata/template marketplace
