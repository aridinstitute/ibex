## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| `⌘K` | Open the command palette |
| `⌘⇧I` | Import a bibliography |
| `F1` | Open documentation |
| `/` | Focus search |
| `N` | Start a new reference |
| `E` | Edit the selected row |
| `Enter` | Toggle the detail editor |
| `F` | Toggle favorite |
| `[` | Toggle the left panel |
| `]` | Toggle the detail panel |
